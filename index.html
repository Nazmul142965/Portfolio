About

I'm a computer science student at Southeast University in Dhaka who likes the parts of software people don't see: a server-side clock, a record that can't be edited afterwards, a test that fails before a user does.

Most of my work is Java, Spring Boot and Go, with MongoDB, Redis and Docker around it. My biggest project, JachAI, is deployed and has 733 Java tests behind it.

Outside the backend I've trained an MRI classifier to 98.5% accuracy, written a 3D harbour in raw OpenGL, and wired up microcontroller circuits. You can read the full list on my résumé.

Projects

  • JachAI: tests and certificates

    Live demo, six one-click roles

    A platform for schools, training centres and hiring teams. The server keeps the clock and the records, AI-drafted questions need a human to approve them, and every certificate can be verified by anyone. 733 Java tests and 176 browser checks.

  • The Chocomuse: store management system

    A desktop app for running a chocolate shop. Admins manage inventory and track sales and revenue; customers browse the catalogue, fill a cart, pay by cash, credit or debit card, and review their order history. Twelve JavaFX screens on top of a layered service design and a MySQL database, with schema and sample-data scripts included.

    • Java 17
    • JavaFX
    • MySQL

  • CampusCollab

    One portal for students, faculty and admins with six modules: skill swaps, events, faculty ratings, projects, chat and careers. Role-based sign-in, backed by a Spring Boot API.

  • Brain tumour MRI classifier

    YOLOv8-Nano sorts MRI scans into glioma, meningioma, pituitary and no tumour at 98.5% validation accuracy, with only 1.4M parameters. Includes training, evaluation and single-image prediction scripts.

    • Python
    • YOLOv8
    • Computer vision

    A harbour with a lighthouse, cargo docks and moving ships, with a day-night cycle, a second "security monitor" viewport and textures generated from maths. Written in C++ and OpenGL with no game engine.
